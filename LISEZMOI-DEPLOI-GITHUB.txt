Deploiement GitHub Pages — blocknums-website

Commande unique (lint + typecheck + build + tests + push) :
  npm run deploy:github-pages

Build + tests sans deploy :
  npm run test:github-pages

Deploy manuel (apres test:github-pages) :
  Copier TOUT le contenu de out/ a la RACINE du repo blocknums-website

IMPORTANT: remplacer tout le contenu (pas de melange ancien/nouveau).
Le dossier assets/ doit exister (ex-_next renomme).
